# SAP MM-inspired Procurement & Inventory Analytics

Enterprise analytics project based on **SAP MM-inspired procurement and inventory concepts**, using synthetic ERP-style data and an Advanced Excel dashboard.

> **Scope note:** this is not a live SAP environment. The project applies SAP MM concepts to a synthetic ERP analytics workflow.

## Business questions

- Which vendors have the best on-time delivery performance?
- Which purchase orders are delayed or partially received?
- Which materials are below reorder point?
- How much procurement spend is concentrated among top vendors?
- Where do invoice mismatches occur?

## Files

- `data/` — synthetic ERP-style raw datasets
- `excel/Procurement_Operations_Dashboard.xlsx` — Advanced Excel model/dashboard
- `docs/` — SAP MM-inspired process and data dictionary

## CV-ready summary

Built a **SAP MM-inspired Procurement Analytics** solution using synthetic ERP data, Advanced Excel, Power Query-ready source structures and KPI reporting to evaluate procurement spend, supplier performance, inventory risk and delivery delays.
