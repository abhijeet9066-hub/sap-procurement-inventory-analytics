# SAP Procurement & Inventory Analytics

Enterprise analytics project based on **SAP MM-style procurement and inventory concepts**, using synthetic exported ERP data and an Advanced Excel dashboard.

## Business questions
- Which vendors have the best on-time delivery performance?
- Which purchase orders are delayed or partially received?
- Which materials are below reorder point?
- How much procurement spend is concentrated among top vendors?
- Where do invoice mismatches occur?

## Files
- `data/` — ERP-style raw datasets
- `excel/Procurement_Operations_Dashboard.xlsx` — Advanced Excel model/dashboard
- `docs/` — SAP MM process and data dictionary

## CV-ready summary
Built a SAP MM-inspired procurement and inventory analytics solution using Advanced Excel, Power Query-ready source structures and KPI reporting to evaluate procurement spend, supplier performance, inventory risk and delivery delays.
